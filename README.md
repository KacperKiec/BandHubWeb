# BandHubWeb 🎸

BandHubWeb is a web-based platform designed for musicians and bands to streamline collaboration, manage musical projects, and network within the industry. The application bridges the gap between social networking and artistic project management.

## 🚀 Features

- **Musician Profiles:** Personalized profiles showcasing instruments, musical genres, skill levels, and experience.
- **Band Finder:** A filtering system to find local musicians or bands looking for new members.
- **Team Management:** A dashboard for internal band communication and rehearsal scheduling.
- **Classifieds:** A dedicated board for users seeking session musicians, gear sales, or offering professional music services.

## 🛠️ Tech Stack

This project is built using the following technologies:

- **Frontend:** Angular / Typescript
- **Backend:** Spring Boot / RabbitMQ
- **Database:** PostreSQL / MongoDB
